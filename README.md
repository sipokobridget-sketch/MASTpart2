# Chef's Menu Manager - Part 2: Building the Mobile Application 

## Overview 
**Chef's Menu Manager** is a React Native mobile application designed to provide a simple and user-friendly interface for chef's to input and view menu items. This version focuses on core functionality: capturing essential menu details (Dish Name, Description, Course, and Price) and display them dynamically as items are added.

---

## Key Features & Functionality 
* **User Interface:** Developed with a clean, readable layout and consistent spacing based on initial design plans.
*  **Capture Menu Information: ** Uses appropriate React Native input components to let chefs specify the ish name, description, course category, and price.
*  **Display Menu Items**  Allows the entry of multiple menu items, automatically updating the displayed list in real- time as each item, automatically updating the displayed list in real-time as each item is successfully added
